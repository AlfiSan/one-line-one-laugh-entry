One funny line, written for the make.fun bounty
[One Line, One Laugh](https://make.fun/bounty/u-deysumbrella-one-line-one-laugh-e0cdcda9):
a phone dies at 1% and its owner stares at the black screen like it owes
an apology. `main.ts` writes the line — 99 characters, one line, plain
words — to `/output/entry.txt`, where the judge reads it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
